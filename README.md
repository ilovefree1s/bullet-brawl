# Bullet Brawl (Paradox Loop 3D)

A first-person time-loop shooter that runs in the browser. Every loop you play comes back as a ghost soldier that fights beside you.

**Play:** https://ilovefree1s.github.io/bullet-brawl/

- **Campaign:** clear rooms by planning across loops. Ghosts hold plates while you fight your way out.
- **Duel (experimental):** 1v1 against a rival. The loser of each round picks a card that powers them up.

Controls: WASD move, mouse look, left click fire, Shift dash, Q force push, E end loop, Tab planning view, Esc pause.

Built with [Three.js](https://threejs.org/). Soldier model made in Meshy.
